# AI-Powered-English-Exam-Generator

Plataforma inteligente para la generación automática de exámenes de inglés utilizando modelos de lenguaje (LLMs). El sistema permite crear evaluaciones personalizadas según nivel, tipo de ejercicio y objetivos de aprendizaje.

Características
Generación automática de exámenes de inglés
Personalización por nivel (A1, A2, B1, B2, etc.)
Diferentes tipos de ejercicios:
Multiple choice
Fill in the blanks
Reading comprehension
Uso de modelos de lenguaje (LLMs)
Interfaz amigable para docentes/usuarios

Tecnologías utilizadas
Python / JavaScript (ajustar según corresponda)
Framework web (React / Node.js / Django / etc.)
APIs de modelos de lenguaje (OpenAI / otros)
HTML, CSS

Arquitectura

El sistema sigue una arquitectura cliente-servidor:

Frontend: Interfaz de usuario para configurar y visualizar exámenes
Backend: Lógica de generación de contenido y conexión con modelos de IA
Módulo IA: Generación de preguntas mediante prompts diseñados

npm install  # o pip install -r requirements.txt

# Ejecutar
npm start  # o python app.py
